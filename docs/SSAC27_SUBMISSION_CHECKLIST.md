# SSAC27 Submission Checklist

- [Official competition rules](https://www.sloansportsconference.com/research-paper-competition)
- [SSAC27 abstract submission form](https://forms.gle/cN4HZVkJdQ13cNL98)

## Completed research materials

- [x] Frozen research protocol and dated amendment
- [x] Complete 2000–2025 cohort analysis
- [x] Frozen modeling specification and checksum
- [x] One-time 2022–2025 locked test
- [x] Primary association and prediction results
- [x] All prespecified sensitivity analyses
- [x] Aggregate tables and two publication figures
- [x] Results and Discussion drafts
- [x] Internal post-analysis audit: 22/22 checks passed
- [x] Test suite: 34 tests passed in the complete workspace
- [x] Release-safe repository package and checksums
- [x] Official public data-source links and executable acquisition code
- [x] Data-availability and redistribution-status statement
- [x] Structured abstract under 500 words

## Author actions before submission

- [ ] Add author names, affiliations, email addresses, and author order.
- [ ] Obtain approval of the abstract and submission from every coauthor.
- [ ] Put the `release/` contents in a public GitHub or equivalent repository.
- [ ] Confirm every link works for a logged-out reader and record the public
      repository URL in the submission form.
- [ ] Add a repository license for original code and prose. Do not apply that
      license to third-party NBA data.
- [ ] Choose the Basketball track.
- [ ] Paste the title and four required abstract sections from
      `SSAC27_ABSTRACT.md`; confirm the form's word counter remains below 500.
- [ ] If using visual material, attach no more than two combined tables and
      figures. Recommended: the primary-results table and birth-year coverage
      figure.
- [ ] Complete conflict-of-interest, originality, rights, and author
      declarations accurately.
- [ ] State that NBA.com is the source of Combine, draft, and profile records.
- [ ] Submit before October 1, 2026, 11:59 p.m. Eastern Time.
- [ ] Save the submitted PDF/text, repository commit hash, timestamp, and
      confirmation receipt.

## Work continuing after abstract submission

- [ ] Request written NBA permission for redistribution of source or derived
      row-level data.
- [ ] Add only the files and fields expressly authorized, with required
      attribution and license language.
- [ ] Obtain an external human methodological review before a full manuscript.
- [ ] If invited, integrate Introduction, related work, Data, and Methods with
      the completed Results and Discussion sections for the full paper.
